# Professional Forex Trading Bot

A comprehensive, modular trading bot for automated forex trading with MetaTrader 5 integration.

## Features

### Trading Strategies
- **Moving Average Crossover**: Classic trend-following strategy
- **RSI Strategy**: Mean-reversion using Relative Strength Index
- **Breakout Strategy**: Volatility breakout trading
- **Scalping Strategy**: High-frequency short-term trading

### Technical Indicators
- Moving Averages (SMA, EMA, WMA, Hull MA)
- Oscillators (RSI, Stochastic, MACD, Williams %R)
- Volatility Indicators (Bollinger Bands, ATR, Keltner Channels)

### Risk Management
- Position sizing based on account risk
- Stop loss and take profit management
- Daily loss limits
- Consecutive loss protection
- Drawdown control

### Data Management
- Real-time market data integration
- Historical data storage and retrieval
- Data cleaning and validation
- Technical indicator calculation

### Analysis & Performance
- Backtesting engine
- Performance metrics calculation
- Signal analysis and optimization
- Trade logging and reporting

### Additional Features
- Email notifications
- GUI dashboard
- Comprehensive logging
- Unit testing framework
